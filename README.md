# MarkovChapter

Локальное Android-приложение для генерации черновиков глав на основе цепей Маркова и правил контекста сцены.

- Kotlin, Jetpack Compose, MVVM + StateFlow.
- Цепь Маркова второго порядка, работает локально без облачных API.
- Импорт TXT, DOC, DOCX, PDF, EPUB, RTF, HTML, ODT, PPTX, XLSX, Markdown, CSV, TSV, XML и JSON.
- Настраиваемый объём генерации: от 1 до 1000 предложений.
- Последовательность модулей: диалог, описание, действие, событие. Каждый модуль можно добавлять многократно, переставлять и удалять.
- Контекст сцены: место и атмосферные признаки из описания влияют на формулировки последующих действий.
- Состояния персонажей: события меняют страх, решимость и знания; эти состояния влияют на последующие реплики и действия.
- Диалоги выбирают участников сцены и чередуют говорящих.
- Защита от точных повторов предложений в пределах одной генерации.
- Начальная, развивающая и завершающая фазы главы.
- Отдельная статистика: объём корпуса, уникальные слова, число переходов, предложения и ориентир по объёму.
- Персонажи, места, имена собственные и пользовательские реплики с весами.
- Локальное хранение настроек и экспорт результата в TXT.

**Ограничение модели:** это статистический генератор с эвристическим состоянием сцены, а не нейросеть с семантическим пониманием. Он создаёт связующие конструкции и меняет игровые параметры персонажей, но не гарантирует литературно корректную причинность или цельный сюжет. Статистика объёма — ориентир, а не гарантия качества.

Сборка: [docs/BUILD.md](docs/BUILD.md). Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

PDF должен содержать текстовый слой; OCR сканов отсутствует. Парольные и DRM-защищённые документы не поддерживаются.
