# MarkovChapter

Локальное Android-приложение для генерации глав на основе цепей Маркова.

- Kotlin, Jetpack Compose, MVVM + StateFlow.
- Цепь Маркова второго порядка без нейросетей и облачных API.
- Импорт TXT, DOC, DOCX, PDF, EPUB, RTF, HTML, ODT, PPTX, XLSX, Markdown, CSV, TSV, XML и JSON.
- Настраиваемое количество предложений (5–20).
- Четыре управляемых модуля главы: диалог, описание, действие, событие. Модули можно включать, выключать и переставлять.
- Персонажи, места, имена собственные и пользовательские реплики с весами.
- Локальное хранение настроек и экспорт результата в TXT.

Сборка: [docs/BUILD.md](docs/BUILD.md). Архитектура: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

**Ограничения импорта:** PDF должен содержать текстовый слой; сканированные изображения без OCR не распознаются. Защищённые паролем документы и неизвестные форматы не импортируются. Старый Word DOC читается через Apache POI; качество извлечения зависит от структуры документа.
