# Архитектура

- `data/MarkovChain` — локальная цепь Маркова второго порядка.
- `data/DocumentTextExtractor` — извлечение текста из TXT/MD/CSV/TSV/XML/JSON/LOG, RTF, HTML, PDF, DOC, DOCX, EPUB, ODT, PPTX и XLSX.
- `data/SettingsStore` — SharedPreferences: сущности, фразы и порядок модулей.
- `data/Models` — персонажи, места, имена, фразы и типы модулей.
- `ui/MarkovViewModel` — MVVM/StateFlow; импорт на IO, обучение на Default.
- `ui/MarkovApp` — Compose UI, системный OpenDocument picker и экспорт через CreateDocument.

## Генерация

Пользователь выбирает от 5 до 20 предложений, включает нужные модули и задаёт их порядок:
1. Диалог.
2. Описание.
3. Действие.
4. Событие.

Предложения распределяются между включёнными модулями поровну (остаток назначается первым модулям в выбранном порядке). Внутри модулей используются цепь Маркова и локальные шаблоны реплик/сущностей.

## Ограничения

- OCR для сканированных PDF отсутствует.
- Парольные/DRM-защищённые документы не поддерживаются.
- Импорт поддерживает перечисленные расширения, а не буквально все существующие форматы.
- Генерация статистическая и не гарантирует причинно-следственную связность сюжета.
- В сеть пользовательские документы не отправляются.
