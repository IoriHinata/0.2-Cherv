# Архитектура MarkovChapter

- `data/MarkovChain` — локальная цепь Маркова второго порядка, словарь, переходы и статистика обучающего корпуса.
- `data/DocumentTextExtractor` — извлечение текста из поддерживаемых документов.
- `data/SettingsStore` — SharedPreferences; сохраняет сущности, пользовательские фразы и упорядоченный список экземпляров модулей.
- `data/Models` — сущности, типы модулей, ModuleStep с уникальным ID и TrainingStats.
- `ui/MarkovViewModel` — MVVM/StateFlow, импорт, обучение, генерация и управление последовательностью модулей.
- `ui/MarkovApp` — Compose UI: обучение, статистика, сущности, генерация.

## Генерация главы

Пользователь задаёт 1–1000 предложений. Последовательность ModuleStep может содержать повторяющиеся типы. Генератор циклически проходит последовательность, пока не создаст нужное число предложений.

Контекст одной генерации хранит:
- выбранное место и атмосферу, извлечённую простыми лексическими эвристиками из описаний;
- список участников сцены и последнего говорящего;
- состояния персонажей: страх, решимость и знания;
- набор уже использованных предложений для снижения точных повторов;
- фазу истории: начало, развитие, завершение.

Описание задаёт контекст для последующих действий. Событие меняет состояния затронутых персонажей. Эти состояния влияют на выбор формулировок в диалогах и действиях. Диалоги выбирают говорящего и собеседника из заданного списка персонажей.

## Статистика обучения

Показываются число слов, уникальный словарь, число переходов между токенами, количество исходных предложений и доля уникальных слов. 50 000 слов используются как ориентир для базовых экспериментов, не как научно установленная гарантия связного текста.

## Ограничения

- Цепь Маркова не понимает смысл и не планирует полноценную драматургию.
- Причинные связи и изменения персонажей реализованы эвристическими правилами.
- Избегание повторов нацелено на точные совпадения, но не гарантирует отсутствие смысловых повторов.
- OCR сканированных PDF отсутствует; защищённые документы не поддерживаются.
- Пользовательские документы не отправляются в сеть.
